ПРАКТИЧЕСКАЯ № 4. GRID, FLEXBOX И АДАПТИВНЫЕ СЕТКИ

1. Откройте index.html в браузере. Без стилей страница будет выглядеть как обычный HTML: так и задумано.
2. Откройте изображения в папке mockups архива. Восстановите дизайн самостоятельно в styles.css.
3. Данные восьми карточек и иллюстрации уже присутствуют в HTML / assets.
4. Обязательные ширины: 320, 375, 768, 1024, 1440, 1920 px.
5. Реализуйте: Grid с колонками, Flexbox для внутренней компоновки, вложенные сетки, адаптивную перестройку секции feature.
6. Проверьте длинный контент, фокус с клавиатуры, отсутствие горизонтальной прокрутки.
7. Чек-лист и подробное ТЗ находятся в ЗАДАНИЕ.txt.

Важно: фильтры в данном макете декоративные (программировать JS-фильтрацию не требуется).
