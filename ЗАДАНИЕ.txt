ПРАКТИЧЕСКАЯ РАБОТА № 4: ПИКСЕЛЬНЫЕ МАКЕТЫ

ЗАДАЧА: по PNG-макетам сверстать страницу «Каталог учебных проектов».

КАРТОЧКИ (ровно восемь; содержание уже в HTML):
1. Help Desk — сервис обработки заявок; Java / Spring Boot; веб-приложение; средний.
2. TaskFlow — доска задач команды; React / TypeScript; интерфейс; базовый.
3. EcoMonitor — мониторинг городской среды; Python / FastAPI; аналитика; сложный.
4. BookSpace — каталог электронной библиотеки; HTML / CSS / JS; веб-приложение; базовый.
5. FinTrack — личный учёт расходов; Vue / PostgreSQL; аналитика; средний.
6. EventHub — платформа мероприятий; Next.js / Prisma; интерфейс; сложный.
7. StudyNotes — совместные конспекты; Java / Thymeleaf; веб-приложение; средний.
8. CityRoutes — планировщик маршрутов; JS / OpenStreetMap; интерфейс; сложный.

КАЖДАЯ КАРТОЧКА ДОЛЖНА СОДЕРЖАТЬ:
- обложку 16:9 (выдана в SVG);
- тип проекта и уровень сложности;
- название, описание и технологии;
- число задач и дату;
- ссылку «Подробнее».
В карточках разная длина заголовков и текста: нижний блок и кнопка выравниваются по нижнему краю.

КОМПОЗИЦИЯ:
- шапка навигации; вводный hero; блок фильтров; каталог из 8 карточек;
- нижний feature-блок «От макета к адаптивной системе» с двумя смысловыми частями;
- футер.

ЭТАЛОННЫЕ ШИРИНЫ:
320 px, 375 px — по одной карточке; меню и hero сокращаются; feature в один столбец.
768 px — две колонки карточек; фильтры переходят над каталогом.
1024 px — две колонки карточек, фильтр слева.
1440 px, 1920 px — три колонки карточек, фильтр слева, ограниченная ширина контейнера.

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:
Использовать CSS Grid для внешней сетки и карточек; Flexbox внутри карточки и в навигации;
minmax(), min-width:0, flex-wrap, gap, box-sizing:border-box.
Рекомендуется применить Container Queries к одному компоненту.
Избегать фиксированной высоты для текстового контента. Без горизонтальной прокрутки.
Убедиться в читаемости элементов и клавиатурной навигации.

КОМПЛЕКТ СДАЧИ:
index.html, styles.css, папка assets, скриншоты на всех шести ширинах,
краткое объяснение выбора Grid/Flexbox и 3 примера адаптивной перестройки.

ПРИМЕЧАНИЕ: рисунки отражают целевую композицию. Небольшие различия в рендеринге
шрифтов и сглаживания допустимы.
