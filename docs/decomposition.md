## 4. Семантическая структура

За основу взят экран каталога.

- `header` шапка сайта: логотип, навигация, поиск. Одинаковая на всех страницах.
- `nav` с `aria-label`, текущий пункт помечен `aria-current="page"`.
- `main` главное содержимое, на странице оно одно.
- `h1` заголовок «Учебные мероприятия», единственный на странице.
- `form role="search"` поиск и сортировка, это именно форма поиска.
- `section` список результатов со своим заголовком.
- `article` одна карточка, она понятна и вне списка.
- `time` с атрибутом `datetime` для даты мероприятия.
- `aside` панель фильтров, это дополнительный блок рядом с основным.
- `fieldset` и `legend` группы фильтров «Дата» и «Формат».
- `footer` подпись проекта.

На странице мероприятия добавляются `role="tablist"`, `role="tab"` и `role="tabpanel"`. В форме
каждое поле связано с `label` через `for` и `id`, текст ошибки привязан через `aria-describedby`.

Переходы сделаны ссылками `a`, действия внутри страницы кнопками `button`. По ссылке можно
открыть страницу в новой вкладке, а кнопка меняет состояние текущей страницы.

| -------------------- | ----------------------- | ------------ | ------------------------------ | ------------------- |
| Сетка карточек       | 3 колонки               | 2 колонки    | 1 колонка                      | 1 колонка           |

Горизонтальной прокрутки быть не должно. У карточек нет фиксированной ширины, сетка собрана на
grid с `1fr`, длинные названия переносятся.
