# CampusFlow

Учебный проект по практической работе №1. Сервис, в котором студент ищет учебное мероприятие,
открывает его карточку и записывается на участие.

Главное в этой работе не полная вёрстка макета, а анализ, декомпозиция и настроенный фундамент
проекта. Поэтому в репозитории есть и код, и документы с разбором макета.

## Установка

```bash
npm install
```

## Команды

| Команда                | Что делает                                |
| ---------------------- | ----------------------------------------- |
| `npm run dev`          | локальный сервер на http://localhost:5173 |
| `npm run build`        | сборка проекта в папку dist               |
| `npm run preview`      | просмотр собранной версии                 |
| `npm run lint:js`      | проверка JavaScript через ESLint          |
| `npm run lint:css`     | проверка CSS через Stylelint              |
| `npm run lint`         | обе проверки сразу                        |
| `npm run format`       | форматирование через Prettier             |
| `npm run format:check` | проверка форматирования без изменений     |
| `npm run check`        | формат, линтеры и сборка подряд           |

## Структура

В корне лежат три страницы: `index.html` это каталог, `event.html` это страница одного
мероприятия, `register.html` это форма регистрации.

Папка `src` разбита по смыслу:

- `src/components` повторяемые куски интерфейса: карточка, пагинация, вкладки;
- `src/pages` скрипт для каждой страницы;
- `src/data` временные данные вместо сервера;
- `src/styles` стили: `base.css` общее, `catalog.css` каталог, `pages.css` две остальные страницы,
  `main.css` собирает всё вместе.

Папка `docs` содержит документы работы, `public` статические файлы. Настройки лежат в корне:
`vite.config.js`, `eslint.config.js`, `.prettierrc`, `.stylelintrc.json`, `.gitignore`.

## Документы

- `docs/decomposition.md` страницы, компоненты, состояния, семантика, адаптивность, риски.
- `docs/practice-1-form.md` заполненная форма-шаблон практической работы №1.
